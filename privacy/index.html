Privacy Policy

Asset Uploader — a private publishing tool operated by Satisvizion.

Last updated: 2 September 2026

In short: Asset Uploader is a single-operator tool that runs on Satisvizion's own computer. It signs in to the operator's own Google Drive to upload the operator's own game build files. It is not a consumer product, it has no other users, and it collects nothing from anyone else.

What this application is

Asset Uploader is an internal publishing utility used by Satisvizion to move finished game artefacts — demo builds, archives and related release files — to storage and distribution destinations. It runs locally on the operator's machine. There is no hosted service, no public sign-up, and no account for anyone other than the operator.

What data the application accesses

When the operator connects a Google Account, the application requests a single Google Drive permission:

  • https://www.googleapis.com/auth/drive.file — access limited to files that this application itself creates or that the operator explicitly opens with it.

This is the narrowest Drive permission Google offers for this purpose. The application cannot see, read or list the rest of the connected Drive. It does not request access to Gmail, Contacts, Calendar, Photos or any other Google service.

What the application does with that access

  • Uploads release artefacts to the connected Drive.
  • Sets link sharing on those uploaded files so that a published demo can be downloaded by people who are given the link.
  • Reads back the resulting file link and sharing state to confirm the upload worked.

It does not modify, move or delete files it did not create.

Where credentials are stored

The Google OAuth token issued after sign-in is stored in a local file on the operator's own computer. It is not transmitted to Satisvizion, to any server, or to any third party. There is no remote database. Revoking access at Google Account permissions immediately and permanently ends the application's access.

What is not collected

  • No analytics, telemetry, tracking pixels or advertising identifiers.
  • No personal data belonging to anyone other than the operator.
  • No data is sold, rented, or shared with third parties — there is no third party.

Data retention

Files uploaded to Drive remain there until the operator deletes them. The stored authentication token remains on the operator's machine until it expires, is revoked, or the local file is deleted.

Limited Use disclosure

Asset Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If what the application does with Google data changes, this page is updated before the change ships, and the date above changes with it.
